# 🧮 Calculator — CodeAlpha Internship

A responsive calculator web app built with **HTML, CSS, and JavaScript** as part of the CodeAlpha Web Development Internship.

## 📋 Overview

This project is a fully functional calculator that performs standard arithmetic operations through a clean, interactive interface. It was built to demonstrate core front-end skills: DOM manipulation, event handling, and responsive UI design.

## ✨ Features

- **Arithmetic operations** — addition, subtraction, multiplication, and division
- **Real-time display** — results update instantly as you type
- **Clear & backspace** — reset the calculator or delete the last digit entered
- **Chained calculations** — perform multiple operations in sequence (e.g. `12 + 8 × 2`)
- **Error handling** — safely handles invalid operations like division by zero
- **Keyboard support** — full calculator control from the keyboard (digits, `+ − × ÷`, `Enter`, `Backspace`, `Esc`)
- **Responsive design** — adapts cleanly to mobile and desktop screens

## 🛠️ Built With

- **HTML5** — structure and layout
- **CSS3** — styling, layout (Flexbox/Grid), and interactive states
- **JavaScript (Vanilla)** — calculator logic and DOM manipulation

## 🚀 Getting Started

### Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Calculator_CodeAlpha-Internship.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Calculator_CodeAlpha-Internship
   ```
3. Open `index.html` in your browser — no build step or dependencies required.
